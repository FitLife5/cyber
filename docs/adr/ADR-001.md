# ADR-001: Вибір технологічного стеку для AI-асистента SOC (React + FastAPI + Ollama)

## Статус
Прийнято (Accepted)

## Контекст (Context)
Центр моніторингу безпеки (SOC) вимагає зручного веб-інтерфейсу в реальному часі для аналітиків кібербезпеки. 
Основні вимоги: відображення алертів у режимі Live (через WebSockets), швидкий аналіз системних логів за допомогою AI без виходу чутливих даних за периметр, а також можливість підключення до векторної бази знань (MITRE ATT&CK, SOC Playbooks).

## Рішення (Decision)
Команда прийняла рішення обрати наступний стек:
- **Frontend**: React 18 / 19 + Vite + TypeScript (UI фреймворк: Tailwind CSS / shadcn/ui).
- **Backend**: Python 3.12 + FastAPI (з підтримкою WebSockets для потокових сповіщень).
- **LLM-інфраструктура**: 
  - *Локально*: Ollama (Llama 3 8B) для приватного аналізу логів.
  - *Хмара*: OpenAI API (GPT-4o) з модулем Sanitizer (для знеособлення PII та IP).
- **AI Framework**: LangChain (для побудови AI-агентів).
- **Vector Database**: Qdrant (RAG по базах знань загроз).

## Наслідки (Consequences)
### Переваги (Positive):
- **Сучасний UX/UI**: React дозволяє створити багатокомпонентну панель аналітика (Dashboard, лог-вівер, AI-чат).
- **Висока продуктивність**: Vite гарантує швидку збірку, а FastAPI — високу швидкість обробки API-запитів.
- **Безпека**: Конфіденційні дані не виходять за межі внутрішнього контуру завдяки локальній LLM.

### Ризики та недоліки (Negative / Risks):
- Необхідність роздільного деплою та налаштування CORS між React-клієнтом та FastAPI-сервером.
- Додаткові вимоги до розділення командних ролей (Frontend vs Backend/AI).
