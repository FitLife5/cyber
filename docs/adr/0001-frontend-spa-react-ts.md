# ADR-0001. Вибір React + TypeScript (SPA) для веб-застосунку

**Статус:** Прийнято

**Контекст:**
Для контейнера «Веб-застосунок» (див. C4 Container) потрібен швидкий, інтерактивний інтерфейс SOC-дашборду з підтримкою роботи в реальному часі, підсвічуванням логів та суворою типізацією даних, що надходять від API.

**Рішення:**
Використати стек React + TypeScript зі збирачем Vite у форматі Single Page Application (SPA).

**Альтернативи:**
- *Next.js (SSR)* — відкинуто, оскільки система є закритим внутрішнім інструментом без потреби в SEO-індексації, а серверний рендеринг ускладнив би розгортання.
- *Чистий HTML/JS без фреймворку* — відкинуто через складність підтримки стану інтерфейсу та відсутність типізації контрактів API.

**Наслідки:**
- (+) Висока швидкість роботи інтерфейсу без перезавантаження сторінок, типізація моделей запитів/відповідей, велика екосистема готових UI-компонентів.
- (−) Початкове завантаження бандлу в браузері займає трохи більше часу порівняно зі статичними сторінками.
