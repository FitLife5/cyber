# ADR-0003. Гібридне зберігання даних: PostgreSQL та векторна БД Qdrant

**Статус:** Прийнято

**Контекст:**
Системі одночасно потрібне надійне реляційне сховище для обліку користувачів, інцидентів та витрат токенів LLM, а також швидкий семантичний пошук по базі інструкцій (Playbooks) для роботи RAG-пайплайну.

**Рішення:**
Використати дві спеціалізовані бази даних (див. C4 Container): **PostgreSQL** (через SQLAlchemy ORM) для транзакційних даних та **Qdrant** для зберігання векторних ембеддингів інструкцій.

**Альтернативи:**
- *Зберігати інструкції у локальному JSON-файлі* — відкинуто, оскільки при зростанні бази знань неможливо робити семантичний пошук і все не вміститься в контекстне вікно LLM.
- *Використати лише SQLite* — відкинуто через блокування при конкурентному записі кількома аналітиками та відсутність повноцінної підтримки векторного пошуку.

**Наслідки:**
- (+) Висока точність пошуку релевантних інструкцій, сувора цілісність даних про інциденти та аудит викликів моделі.
- (−) Потрібно підтримувати два контейнери баз даних та синхронізувати видалення/додавання інструкцій між ними.
